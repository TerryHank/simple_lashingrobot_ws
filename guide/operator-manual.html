浏览器前端全功能图文手册 ​

本页面面向现场操作和调试人员，说明 http://127.0.0.1:8080/index.html 中每个主要入口怎么用、什么时候用、会触发哪条链路，以及成功或异常时该看哪里。

现场口诀：先看顶部状态，再确认工作区生成账本，最后执行全局绑扎；调试、灯光、跳绑、分类和遥控都在对应功能区操作。

浏览器界面总览 ​

下面第一张图是当前前端在浏览器中的整页截图。离线状态下部分胶囊会显示未连接；现场在线后，顶部 ROS、索驱、末端、视觉会按实时状态变色。

第二张图是区域标注图，用来快速定位每个功能区。

1. 打开页面与顶部状态 ​

浏览器入口：

text
http://127.0.0.1:8080/index.html

顶部工具条从左到右分为 4 类：

区域用途操作说明
面板按钮控制面板、图像、设置、终端、日志点击后显示或隐藏对应浮动面板。
ROS 连接连接 rosbridge、本机 ROS master 和前端桥接未连接时可点击「启动 ROS」或「手动重连」。连接成功后，长按可重启 ROS。
电压显示机器人电压和 ROS 后端启动状态电压未获取时通常说明后端或驱动未完全在线。
状态胶囊索驱、末端、视觉、演示模式胶囊变绿表示对应子系统在线；黄色表示告警；红色或灰色时可短按启动/关闭，长按 0.5 秒重启。

子系统胶囊 ​

胶囊对应层常用动作
索驱tie-robot-driver-suoqu.service启动、关闭、重启索驱驱动，不影响末端和视觉。
末端tie-robot-driver-moduan.service启动、关闭、重启线性模组驱动，不影响索驱和视觉。
视觉相机驱动 + pointAI 算法层启动、关闭、重启视觉子系统。
演示模式本工程运行栈静默开关进入后会停止本工程 ROS 后端、rosbridge 和驱动守护；退出后按依赖顺序恢复。

顶部连接状态只表达 ROS / rosbridge 连接；索驱、末端、视觉报警会落在各自胶囊和日志里。

2. 控制面板：现场主流程按钮 ​

控制面板是日常操作主入口，分为「扫描区」「执行层」「区域切换」。

分组按钮什么时候用后端链路
扫描区触发扫描视觉工作区已确认后，重新识别当前识别位姿的绑扎点账本。/web/cabin/start_pseudo_slam_scan
扫描区清除所有绑扎点清空所有识别位姿下的扫描账本。前端 API 清理扫描产物
执行层执行全局绑扎已生成 pseudo_slam_bind_path.json 后，开始自动分区绑扎。/web/cabin/start_global_work
执行层触发单点绑扎在当前工作区内做一次原子单点链路：视觉识别、线模执行、等待完成。/moduan/sg
执行层单点视觉测试只触发执行层视觉，不执行线性模组。/pointAI/process_image request_mode=4
执行层记忆续跑开始按 bind_execution_memory.json 跳过已成功点，从未完成点继续执行。/web/cabin/start_global_work，use_execution_memory=true
区域切换上一个区域 / 下一个区域自动执行暂停或现场人工接管后，切到相邻区域。发布 /web/cabin/manual_area_takeover，线模回零，再移动索驱到目标 cabin_pose

全局遥控速度 ​

控制面板下方有 2 个速度输入：

  • 「索驱全局移动速度」：影响索驱遥控、识别位姿移动和人工切区速度。
  • 「TCP 线模执行速度」：影响 TCP 线性模组遥控速度。

速度设置不会自己启动任务，只改变后续移动指令的速度参数。

3. 底部快速控制：扎丝、灯光、跳绑和分类 ​

底部快速控制区用于现场高频开关，和控制面板主流程按钮不同，它们通常只改变运行状态或发布控制话题。

按钮用途操作方式说明
暂停作业 / 恢复作业暂停或恢复执行链长按暂停，短按或状态切换恢复暂停后可继续当前流程；长按停止并回起点会结束当前自动链。
开启绑扎 / 关闭绑扎开启或关闭末端扎丝执行单击切换现场说「开启扎丝」通常就是打开这个开关；关闭后线模可运动，但末端绑扎动作会被关闭。
长按开启跳绑黑棋 / 白棋只绑黑棋或只绑白棋长按启停，单击切换黑/白棋开启后，全局执行、账本测试和微调执行只下发当前颜色的账本点。
开启分类 / 关闭分类开启绑扎点已绑/未绑分类过滤单击切换开启后，执行层视觉会把已绑扎点标记为 blocking 并过滤；未绑扎和不确定点继续下发。
开启灯光 / 关闭灯光控制末端灯光单击切换用于现场补光或观察绑扎点。

底部还显示：

  • 「机器位置」：索驱当前 X/Y/Z。
  • 「区域进度」：当前区域和总区域数。
  • 「线模本地 / 线模全局」：线性模组本地行程和投到全局后的 TCP 位置。

「线模本地」区域支持长按 0.5 秒回零。回零前确认末端附近没有干涉。

4. 得到账本：从工作区到扫描产物 ​

账本是全局绑扎的前置条件。当前工程主要使用 3 个产物：

文件生成时机用途
pseudo_slam_points.json扫描视觉完成后保存扫描识别出的全局绑扎点。
pseudo_slam_bind_path.json扫描规划完成后保存分区、每区 cabin_pose 和每组线模点位。
bind_execution_memory.json扫描时重置，执行时回写记录已成功绑扎点，供记忆续跑使用。

标准操作顺序：

  1. 在顶部确认 ROS、索驱、末端、视觉状态可用。
  2. 打开「设置」面板，当前页切到「工作区选点」。
  3. 选择或新增「识别位姿序号」。
  4. 点击「记录当前位姿」，把当前索驱位置保存为该识别位姿。
  5. 点击「移动到选中位姿」，让索驱回到需要识别的位置。
  6. 在「图像」面板中点 4 个工作区角点。
  7. 点击「确认工作区域」。
  8. 前端收到 pointAI 保存确认后，会自动触发当前画面的 Surface-DP 扫描识别。
  9. 需要重跑当前画面时，点击控制面板「触发扫描视觉」。

成功后看 3 个位置：

  • 图像面板出现扫描识别覆盖层。
  • 设置页「显示与视角」或 3D Scene 中出现规划点、成组和索驱路径。
  • 日志里出现扫描建图完成、规划点数或账本写入信息。

如果提示「未找到 pseudo_slam_bind_path.json」，说明还没有成功完成扫描建图，不能直接执行全局绑扎。

5. 执行全局绑扎、续跑和人工切区 ​

全局执行前建议确认：

  • pseudo_slam_bind_path.json 已存在。
  • 索驱、末端、视觉胶囊在线。
  • 「视觉调试」中的执行模式符合现场目标。
  • 如需跳绑，先在底部快速控制里长按开启跳绑，并单击选择黑棋或白棋。
  • 如需已绑/未绑过滤，先开启「分类」，并确认分类方法。

执行按钮：

按钮行为
执行全局绑扎从账本首区开始，索驱移动到 area.cabin_pose，线模执行 group.points[].x/y/z，成功点写入执行记忆。
记忆续跑开始保留 bind_execution_memory.json，跳过已成功点，从未完成点继续。
单点视觉测试只看执行层视觉效果和点数，不执行扎丝。
触发单点绑扎当前工作区内执行一次视觉 + 线模 + 等待完成的原子链路。
上一个区域 / 下一个区域人工接管自动链、线模回零、索驱移动到相邻区域。

执行模式在「设置 → 视觉调试」中选择：

模式适用场景
执行账本完全按扫描账本执行，不做执行层视觉微调。
账本 + 微调默认推荐模式，用账本定位区域，再用执行层视觉微调当前点。
规划路径 + 纯微调用规划路径到区，到位后主要依赖执行层视觉输出。

6. 图像面板 ​

图像面板用于看相机图像和视觉覆盖层。右上角可切换话题：

图像话题用途
红外图像工作区 4 点选点、识别覆盖层、现场主视图。
彩色图像观察现场 RGB 画面。
深度图像排查深度缺失和遮挡。
滤波世界点云图查看滤波后的世界点云图像。
原始世界点云图查看未经滤波的世界点云图像。
扫描识别底图查看 Surface-DP 扫描诊断底图。
执行视觉底图查看执行层 Hough 或 Surface-DP 微调诊断底图，分类开启后会叠加 BND / UNB / UNC。

红外图像支持：

  • 工作区 4 角点选择。
  • 扫描点覆盖层。
  • 执行视觉结果覆盖层。
  • 悬停坐标读取，坐标系可在「显示与视角」里选择 map、gripper_frame 或 Scepter_depth_frame。

7. 设置页全功能 ​

设置面板顶部「当前页」可切换不同配置页，并支持调整页面顺序。

7.1 话题总览 ​

显示前端已知和运行时发现的话题，帮助判断数据是否到达。适合排查：

  • 相机图像是否发布。
  • /tf、/tf_static 是否正常。
  • 扫描、规划、日志、控制话题是否在线。

7.2 节点日志 ​

按节点聚合最新日志。适合快速判断某个层级是否在报错：

  • 视觉算法节点。
  • 索驱流程节点。
  • 线性模组节点。
  • Web 桥接节点。

7.3 视觉调试 ​

这是现场算法和执行口径的核心设置页。

设置用途
执行层模式选择「执行账本」「账本 + 微调」「规划路径 + 纯微调」。
扫描底图选择 Surface-DP 使用的响应源，例如融合实例响应、Hessian、Frangi、深度梯度、红外响应等。
执行层视觉在 Hough微调 和 扫描同款Surface-DP 之间切换。
分类方法选择深度学习或白盒算法。
释放帧数设置视觉稳定后最终放行帧数。
索驱规划 Z扫描规划时的索驱 Z 目标或下限。
梁筋过滤半径开启梁筋过滤时，梁筋候选周围过滤半径。
成行 / 成列阈值规划分组时判断行列归属的毫米阈值。
账本微调 XY 阈值账本 + 微调模式下，视觉点归到全局棋盘行列中心的 XY 接纳阈值。
自适应每组绑扎点数开启后由规划层动态决定每组点数。
启用梁筋过滤扫描层过滤梁筋候选附近的绑扎点。
底层坐标线性补偿对扫描底层坐标做光轴偏移或整体平移补偿。
绑扎 X/Y/Z min/max设置执行层 TCP 线模可达盒，默认 X 0-380、Y 0-330、Z 0-160 mm。
相机-TCP 外参热更新 Scepter_depth_frame -> gripper_frame 外参。

设置变化会尽量热发布到 ROS，不需要额外点「确认」。

分类方法的算法原理、深度学习链路和白盒效果图见：绑扎点分类原理与效果。

7.4 相机底层 SDK 调试 ​

用于热更新相机 SDK 参数，常见项包括：

  • 帧率。
  • 红外增益。
  • 彩色分辨率。
  • 动态范围模式。
  • 深度曝光时间。
  • 飞点过滤、置信度过滤、时域滤波、空间滤波、空洞填充。
  • 工作模式、软件触发、深度点云和彩色对齐点云。

7.5 国标接入 ​

填写 GB28181 上级平台参数：

  • 上级平台 SIP IP / 端口。
  • 平台国标 ID。
  • 国标域。
  • 接入密码。
  • 本机 SIP IP / 端口。
  • 本机设备 ID。

填写完成后点击「写入本机配置」。需要平台侧接入时，再参考 GB28181 视频接入。

7.6 网络配置 ​

用于保存并测试上位机网络：

  • 索驱上位机 IP，默认 192.168.6.62。
  • 线性模组上位机 IP，默认 192.168.6.167。

点击「保存并测试」后，看结果区是否连通。

7.7 工作区选点 ​

用于生成扫描账本，详见「得到账本」章节。关键按钮：

  • 新增位姿。
  • 删除位姿。
  • 记录当前位姿。
  • 移动到选中位姿。
  • 确认工作区域。
  • 撤销最后一点。
  • 清空重选。

7.8 显示与视角 ​

控制 3D Scene、图像覆盖层和点云显示。

控件用途
自由视角 / 相机视角 / 俯视视角快速切换 3D Scene 观察角度。
跟随原点让视角跟随当前机器原点。
图像悬停坐标选择悬停坐标显示在 map、gripper_frame 或 Scepter_depth_frame。
模式一键切换只显示点云、只显示规划点、点云 + 规划点、只显示机器或全开。
点云源选择滤波世界点云或原始世界点云。
图层开关单独显示或隐藏机器、坐标轴、点云、规划点、行列连线、2x2 成组、索驱路径、线模范围区域、图像识别结果、扫描层识别点。
坐标轴明细单独控制 map、base_link、Scepter_depth_frame、gripper_frame 坐标轴。
点大小 / 点透明度调整点云和点位显示效果。

7.9 Home 点位 ​

用于索驱 Home 标定：

  • 「刷新」读取当前 Home。
  • 「当前位置设为 Home」把当前索驱位置写入输入框。
  • 「保存」保存 Home 标定。
  • 「回 Home」移动到 Home。

base_link -> 相机 信息由 TF 链计算，通常不用人工填写。

7.10 索驱遥控 ​

用于手动移动索驱。

控件用途
开启键盘遥控开启全局键盘控制，Q/W/E = Z+/X+/Z-，A/S/D = Y+/X-/Y-，空格暂停。
单次点击步距设置按钮点动步距。
绝对点动 / 相对点动绝对点动按当前坐标计算目标；相对点动按增量移动。
上、下、X+、X-、Y+、Y-手动点动索驱。
索驱停止移动立即停止索驱当前移动。
绝对目标位姿填 X/Y/Z 后点击「移动到绝对位姿」。

7.11 TCP 线模遥控 ​

用于手动移动末端线性模组。

控件用途
Z+ / Z-调整线模 Z。
X+ / X-调整线模 X。
Y+ / Y-调整线模 Y。
角度+ / 角度-调整末端角度。
运动暂停停止当前线模运动。
单次线性步距设置 X/Y/Z 点动步距。
单次角度步距设置角度点动步距。

行程提示默认是 X 0-380 mm、Y 0-330 mm、Z 0-160 mm。

8. 3D Scene 和图层 ​

3D Scene 是整个页面背景层，不是单独小卡片。它显示：

  • 机器模型。
  • TF 坐标轴。
  • 原始或滤波点云。
  • 扫描识别点。
  • 规划点 / 绑扎点。
  • 行列连线和 2x2 成组。
  • 索驱路径。
  • gripper_frame 下的线模绑扎范围。

推荐使用：

  • 扫描后打开「规划点/绑扎点」「行/列连线」「2x2 成组」「索驱路径」，确认账本是否合理。
  • 执行前打开「线模范围区域」，确认当前点是否落在线模可达盒内。
  • 排查 TF 时打开坐标轴明细，看 map -> base_link -> Scepter_depth_frame -> gripper_frame 是否连续。

9. 日志和终端 ​

日志面板 ​

日志面板可切换来源：

  • 全部终端。
  • 算法层。
  • 索驱。
  • 线性模组。
  • 相机驱动。
  • Web 桥接。

现场排查建议：

  • 扫描失败先看算法层和相机驱动。
  • 全局执行失败先看索驱、线性模组和算法层。
  • 浏览器按钮无响应先看 Web 桥接和顶部 ROS 连接。

终端面板 ​

终端面板支持：

  • 新建本机 Ubuntu Shell。
  • 切换多个终端标签。
  • 关闭终端。
  • 恢复已有会话。

终端适合现场临时查看 systemctl status、rostopic echo 或运行小工具；危险命令先确认当前作业已停止。

10. 常见提示和处理 ​

提示或现象常见原因处理
ROS 未连接，无法执行rosbridge 或 ROS 后端未在线点顶部「启动 ROS」或重启 ROS。
当前没有已保存工作区还没点满 4 个角点并确认工作区域进入「工作区选点」，重新选 4 点并确认。
未找到 pseudo_slam_bind_path.json没有成功完成扫描建图先确认工作区，再触发扫描视觉。
视觉无点或点数异常工作区、相机、深度或执行视觉参数不合适看图像面板的扫描底图 / 执行视觉底图，再调视觉调试参数。
人工切区失败读不到账本区域或当前区域未知确认 pseudo_slam_bind_path.json 存在，并等待区域进度或索驱位置上报。
索驱/末端/视觉胶囊黄色对应层级有告警查看该层日志，必要时只重启该子系统。
灯光或扎丝无反应末端驱动未在线或控制话题未到达确认末端胶囊在线，再看线性模组日志。

生成账本并全局绑扎 ​

text

text
