绑扎点分类原理与效果 ​

本页说明执行层「分类」功能的两种方法：深度学习和白盒算法。它们都服务于同一个现场目标：在执行层视觉已经找到候选绑扎点之后，判断该点是不是已经绑过；如果判断为已绑扎，并且分类处于 blocking 模式，就把该点从本次执行点里过滤掉。

当前默认配置是 mode=off、method=deep_learning。前端底部「开启分类」会把模式切到 blocking；「设置 / 视觉调试 / 分类方法」决定使用深度学习还是白盒算法。

总览 ​

分类只接在执行层视觉后面，不参与扫描建图账本生成。

text
执行到位或单点视觉测试
-> /pointAI/process_image request_mode=4
-> Hough微调 或 扫描同款Surface-DP
-> TCP 执行盒过滤
-> 全局工作区过滤
-> 绑扎点分类
-> bound 已绑扎：blocking 模式下过滤
-> unbound / uncertain：继续下发给执行层

执行视觉底图会叠加分类诊断：

标记含义执行动作
BNDbound，已绑扎blocking 模式下过滤，不下发。
UNBunbound，未绑扎保留，继续下发。
UNCuncertain，不确定保留，继续下发，避免误删。

运行配置入口：

  • src/tie_robot_perception/config/bind_point_classification.yaml
  • /web/pointAI/set_bind_classification_enabled
  • /web/pointAI/set_bind_classification_method

代码入口：

  • src/tie_robot_perception/src/tie_robot_perception/pointai/bind_point_classification.py
  • src/tie_robot_perception/src/tie_robot_perception/pointai/process_image_service.py
  • src/tie_robot_perception/src/tie_robot_perception/pointai/execution_refine_hough.py
  • src/tie_robot_perception/tools/bind_point_modality_sweep_report.py

深度学习分类 ​

深度学习分支复用了 5.18auto.py 里的核心做法：围绕每个候选点裁剪红外局部块，用候选点的 raw_z 做深度带掩膜，再把清理后的 patch 输入 YOLO 分类模型。

关键步骤：

  1. 执行层视觉先给出候选交点，包含像素坐标和相机坐标。
  2. 在红外图上以候选点为中心裁剪局部 patch。
  3. 用深度图保留 raw_z ± 75 mm 的同层像素，其他像素置黑。
  4. 将 patch 缩放到 128 x 128。
  5. 使用 CLAHE 做局部对比度增强。
  6. 调用 best.pt YOLO 分类模型。
  7. class 0 解释为已绑扎，class 1 解释为未绑扎。

默认参数：

配置项当前值说明
deep_learning_model_path/home/hyq-/simple_lashingrobot_ws/best.ptYOLO 分类模型路径。
deep_learning_confidence0.2推理置信度阈值。
deep_learning_depth_tolerance_mm75.0深度掩膜上下容差。
deep_learning_bound_class_id0已绑扎类别。
deep_learning_unbound_class_id1未绑扎类别。

深度学习适合有稳定训练样本后上线：它能把人工经验浓缩进模型，但需要持续维护样本集、模型文件和现场域差异。分类关闭时，运行时不会加载 YOLO 模型，避免影响原有执行链路。

白盒分类 ​

白盒方法对应运行配置里的 method=white_box，不依赖模型文件。它把候选点周围的 raw_world 深度、IR 暗线、CLAHE 暗线、深度梯度、斜向绑丝残差、中心凸包紧致块和轴向保护合在一起判断。

白盒算法的核心判断：

证据解释
轴向保护普通十字钢筋主要由水平 / 垂直两条轴解释，不能仅因中心亮就误判。
离轴斜丝残差已绑扎点常出现短斜向扎丝或结节，去掉钢筋轴线后仍有残差。
中心紧致块扎丝结节可能表现为中心局部凸起、面积紧凑、凸包填充较高。
高度差raw_world 局部背景深度减当前深度，用来寻找高出平面的结构。
IR 暗线与 CLAHE红外暗线和局部增强后暗线提供纹理辅助。
脊线破坏未绑扎交点的两条钢筋脊线更连续，已绑扎结节会破坏中心连续性。

白盒输出仍然只有三态：

  • bound：已绑扎，blocking 模式过滤。
  • unbound：未绑扎，继续执行。
  • uncertain：证据不足，继续执行。

和执行层视觉的关系 ​

分类不替代执行层找点。执行层视觉先决定“哪里可能需要绑”，分类只决定“这个候选点是否已经绑过”。

执行层视觉分类接入位置
Hough微调Hough 候选点经过 TCP 执行盒、全局工作区和蛇形排序后进入分类。
扫描同款Surface-DPSurface-DP 执行分支输出执行层过滤后的点，再进入同一套分类。

两个执行分支共用同一套分类结果叠加：分类开启后，/perception/lashing/execution_refine_base_image 会重新发布带 BND / UNB / UNC 的执行视觉底图。

现场使用建议 ​

  1. 默认先保持分类关闭，确认执行层视觉点位本身稳定。
  2. 需要过滤已绑点时，先开启分类，再在「设置 / 视觉调试」选择方法。
  3. 深度学习适合模型样本稳定后使用；如果模型缺失或推理失败，结果会回到 uncertain，不会误删点。
  4. 白盒适合现场快速排查和无模型兜底；如果普通十字交点被误判，优先看轴向保护、离轴斜丝和中心块指标。
  5. 现场复盘时先看执行视觉底图的 BND / UNB / UNC，再打开完整分类报告查看每个点的 score、quality 和 reason。
